# TrayProxy

**TrayProxy** — небольшое приложение для Windows, позволяющее быстро включать и выключать системный ручной прокси через значок в системном трее.

## Возможности

- Включение и выключение системного прокси одним нажатием.
- Цветовая индикация состояния: зелёный — включён, серый — выключен.


Перед использованием убедитесь, что ручной прокси-сервер уже настроен в Windows и доступен по указанному адресу.
